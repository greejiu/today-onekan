## 3. 화면 구성

- 사이드바: 🏠집 / 🗓️일정 / ✔️할일 (+설정)

- **일정**: 목록/캘린더 보기 전환. 메모 토글은 09-12 제거됨(이제 일정만 관리).
- **할일**: 할일↔습관 토글(습관 관리 목록) + 다가오는 계획 7일 보드 + 언젠가 관리.

## 4. 확정된 공통 인터랙션 규칙 (집 화면 기준, 구현됨)
- 빈칸 왼쪽 클릭 = 할일 바로 추가
- 빈 공간 오른쪽 클릭 = "일정 추가 / 할일 추가" 선택 메뉴 (`showAddKindMenu`)
- 기존 항목 오른쪽 클릭 = 날짜변경 / 태그변경 / 습관↔할일 전환 / 복제 / 삭제 (`showAgendaItemMenu`)
- 기존 항목 짧은 클릭 = 이름 인라인 수정
- 드래그 = 다른 날짜·시간으로 이동 (`homeDropZone` + `moveItemToZone`)
- 체크박스·리드 자리 폭 20px(타임라인 14px)로 통일, 태그/범주 색으로 채움
- 타임블럭/언젠가/다가오는계획 = 글자색으로 태그 구분, 타임라인 = 배경색으로 구분
- 위 규칙은 현재 **집 화면에만** 적용돼 있고, 일정/할일/습관 각 탭 자체 목록엔 아직 미적용 (7장 백로그 참고)
