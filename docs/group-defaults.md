# 그룹의 기본 항목과 색상

최신 main `060adde62fe25463a7edf1bfa94250711188c9c1`에서 변경했다.

- 일정·할일·습관 그룹에서 보관/복원과 보관 목록 전환을 제거했다. 기존 보관 그룹은 읽을 때 일반 그룹으로 취급하며 저장된 행과 연결은 수정하거나 삭제하지 않는다.
- 그룹을 지정하지 않은 항목은 **기본**으로 표시한다. 기존 `null` 연결과 필터 ID `none`을 유지해 새 그룹 행을 만들지 않는다. 그룹별 목록/보드와 편집창의 그룹 선택도 같은 이름을 사용한다. 프로젝트나 범주의 미지정 표시는 별개다.
- PC에서 기본의 ⋯ 또는 오른쪽 클릭 → 색상 수정, 모바일에서 그룹 관리 → 기본 색상 수정으로 색상을 지정한다. 이름은 기본으로 고정한다. 기존 달력 눈 토글은 유지한다.
- 기본 색상은 `tok_settings.default_group_colors` JSON의 `event`, `todo`, `habit`에 사용자별로 저장한다. 선택한 색상은 그룹의 점과 해당 종류의 기본 항목 보기 색상에 반영한다. 기존 범주 색상과 탭·시간 설정을 보존하는 부분 upsert를 사용한다. 일정의 이전 기본 색상은 새 색상을 설정하기 전까지 사용한다.
- 저장 실패 시 편집창과 입력을 유지한다. 계정 변경 시 색상 캐시를 초기화하고 인증 사용자 일치를 확인해 저장한다.

배포 전에 `supabase/migrations/20261005003201_tok_default_group_colors.sql`을 적용한다. nullable JSON 컬럼과 객체 형식 검사만 추가하고 기존 사용자 데이터와 소유자 RLS는 유지한다.

검증: `group-defaults`, `todo-sidebar`, `schedule-panels`, `shared-view-tabs`, `navigation-settings`, `home-layout`. 테스트는 외부 요청을 차단한다. 기본 색상의 종류별 저장·재조회·부분 저장·실패 복구, 기존 보관 그룹 표시, 기본의 눈 토글, 모바일 편집 및 기존 그룹 연결/드래그를 확인했다. 운영 DB는 컬럼·제약조건·RLS 메타데이터로 확인하며 실제 사용자 행을 테스트로 변경하지 않았다.
