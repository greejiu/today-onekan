# 프로젝트 → 오늘 할 일 연결 (2026-10-01)

## 무엇이 바뀌었나

### 1. 프로젝트 상세의 '오늘하기'

- 대상: 프로젝트 상세의 **미완료·반복 없는 할일**. 줄 오른쪽 '연결 해제' 왼쪽에 버튼(모바일은 날짜 줄 오른쪽).
- 동작: 남아 있는 할일 '오늘로'와 같은 저장(`saveTodoToToday`)을 함께 씀.
  - 같은 행의 `start_date`를 오늘로, `todo_time`은 비움(→ 지금 한칸 '하루종일'에 표시). 새 행을 만들지 않음.
  - 제목·그룹·소요 시간·프로젝트 연결·하위 행동 등 나머지 칸은 그대로.
- 이미 오늘인 할일은 버튼 대신 '오늘 예정'(다시 실행할 수 없음). 저장 중에는 버튼을 잠금.
- 완료한 할일·습관·반복 할일에는 표시하지 않음.
- 저장 성공 → 지금 한칸·할일·작업 화면을 다시 그리고 "오늘 할 일에 담았어요 · 실행 취소"(6초).
- 실행 취소 → 바뀐 칸(`start_date`, `todo_time`)만 원래 값으로. 그사이 날짜·시간·완료 상태가 바뀌었으면 덮어쓰지 않고 알림.
- 저장 실패 → 성공 안내 없이 버튼을 원래대로 돌림.

### 2. 목록의 프로젝트명 표시

- 지금 한칸(타임라인 하루종일·시간칸, 시간블럭 하루종일·블럭, 남아 있는 할일)과 할일 탭에서
  프로젝트에 연결된 할일은 `프로젝트명 - 할일명`으로 보임.
- 바로 연결된 프로젝트 이름만 씀(상위 경로 X). 화면에서만 조합하고 DB 제목은 그대로.
- 프로젝트 없는 할일·습관·일정·담아두기, 프로젝트 상세 안은 기존 제목 그대로.
- 그룹색·완료 흐림/취소선·말줄임은 프로젝트명까지 같이 적용.
- 이름 인라인 수정은 화면 글자가 아니라 원본 제목을 불러옴(프로젝트명이 제목에 저장되지 않게).

## 정한 것과 남은 쟁점

- **시간 처리**: 코드의 기존 '오늘로'(남아 있는 할일)는 시간을 비워 종일로 옮김. 설계 문서
  `집_3열_타이머_공통메뉴_설계.md`의 '오늘 하기'(후속, 미구현)는 "기존 시각 유지". 둘이 충돌 → 이번엔 구현된 쪽(종일로)을 따름.
- **반복 할일 제외**: 시작일을 옮기면 다음 회차 계산 기준도 같이 밀림(원래 예정일 칸 없음,
  `할일_습관_메뉴_반복처리_설계.md` 3장). 반복 규칙을 바꾸지 않는 범위라 이번엔 제외.
- **프로젝트명 표시 옵션**: `SHARE_V1.md` 후속 B안은 프로젝트별 켜기/끄기 옵션. 이번엔 사용자 지시대로 항상 표시(옵션 없음, DB 변경 없음).
- '다가오는' 열·공유 이미지에는 프로젝트명을 붙이지 않음(이번 범위 밖).
