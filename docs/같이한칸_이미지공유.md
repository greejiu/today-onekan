# 같이 한칸 — 앱 이미지와 수기계획 사진

2026-10-02 · 기존 1차 구현(main `d90886f`)에 추가.

## 사용 흐름

- 지금 한칸 / 기록의 **이미지로 공유 → 같이 한칸에 올리기**: 표시 옵션을 적용한 현재 PNG를 바로 넘긴다. 먼저 다운로드할 필요는 없다. 기존 이미지 저장과 기기 공유 버튼은 유지한다.
- 같이 한칸 **이미지로 공유·인증**: 앨범/파일 선택 또는 **사진 촬영**으로 수기계획·그림을 올린다. 카메라 선택은 브라우저/기기 지원에 따라 달라지며 앨범/파일 선택도 계속 제공한다.
- 두 경로 모두 ‘계획 공유 / 완료 인증’ 중 선택하고 이미지 미리보기를 확인한 뒤 명시적으로 제출한다. 사진 선택이나 앱 이미지 전달 자체는 업로드·공개하지 않는다.
- **계획 공유**: 이미지 전체를 하나의 약속으로 취급한다. 제목·예정일·직접 정한 양의 정수 점수를 입력한다. OCR이나 이미지 속 항목별 자동 점수 배정은 하지 않는다. 계획 공유 시 적립 없음.
- **완료 인증**: 기존 내 계획 중 아직 인증하지 않은 것을 고르고 설명을 입력한다. 사진과 설명 제출 후에도 즉시 적립되지 않고, 상대가 확인해야 약속한 점수를 한 번 적립한다.
- 이미지 생성 당시 계정과 현재 계정이 다르면 전달을 막는다. 방이 없으면 먼저 방 생성/초대 참여를 안내하고 기존 공유 화면을 유지한다. 전달 도중 공유 화면을 닫거나 다른 이미지로 바꾸면 늦은 결과로 입력창을 열지 않는다.

## 저장·권한

`20261002111004_tok_together_plan_images.sql`은 기존 `tok_pair_plans`에 nullable `image_path`만 추가한다. 기존 계획·점수·인증 이력은 바뀌지 않는다. public RPC는 계획 생성만 새 private 함수로 전달하고 나머지 기존 검증을 재사용한다.

새 함수는 방 행 잠금, 작성자와 업로드 경로/파일 존재 확인, 기존 계획 생성 검증을 한 트랜잭션에서 수행한다. 저장 재시도는 기존 계획 이미지를 교체하지 않는다. 인증 후 이미지를 바꿀 수도 없다.

계획 이미지는 기존 비공개 버킷을 사용한다. 업로드만 된 파일은 본인에게만 보이고, 계획 저장 후 같은 방 참여자가 볼 수 있다. 제3자는 접근하지 못한다. 초안 일기 사진의 권한은 유지한다.

JPEG/PNG/WebP/GIF, 최대 8MB. 큰 앱 이미지는 표시할 항목을 줄여 다시 만든다. 실패한 경우 양식과 미리보기를 유지하며, DB 응답 유실 뒤 재시도에는 이미 올린 파일을 재사용한다. 저장 도중 입력은 잠근다. 저장하지 않은 입력은 새로고침 시 복구되지 않는다. 고아 파일 정리는 기존 후속 범위다.
