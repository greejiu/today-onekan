## 저장과 권한

`tok_pair_` 접두사의 rooms/members/invites/plans/proofs/ledger/rewards/diaries/replies를 추가한다. 방과 참여자 목록을 사용하며 user1/user2 구조는 없다. 모든 행은 방·작성자 또는 소유자를 식별한다. proof에 확인자와 확인 시각을 보존한다.

읽기는 RLS, 쓰기는 비공개 스키마의 검증 함수와 공개 SECURITY INVOKER RPC 래퍼를 사용한다. 방 행 잠금으로 정원, 적립, 보상 잔액 검증과 쓰기를 직렬화한다. 계정당 방 하나는 unique 제약으로 보장한다. 인증당 ledger 적립 1회, 보상당 차감/취소 각각 1회 제약을 둔다. 요청 ID를 재사용해 응답 유실 후 재시도에도 중복 생성하지 않는다. 서버 한곳의 capacity 함수는 2를 반환한다.

사진은 비공개 `tok-pair-images` 버킷의 `방/작성자/랜덤파일` 경로에 저장한다. 업로드는 참여자·본인 경로만, 읽기는 본인 또는 공개된 인증/일기에 연결된 방 참여자만 가능하다. 미공개 일기 사진은 상대에게 노출되지 않는다. 브라우저는 인증된 download 후 blob URL로 표시하고 화면 갱신/계정 전환 시 해제한다. 공개 URL/장기 signed URL은 사용하지 않는다. SVG는 받지 않으며 JPEG/PNG/WebP/GIF, 최대 8MB다. 증빙 파일 덮어쓰기·삭제 권한은 제공하지 않는다. 실패한 업로드의 고아 파일 정리는 후속 운영 작업이다.

원본 연결은 서버에서 소유권을 검증하고 제목만 복사한다. 개인 메모·첨부는 읽어 공유하지 않는다. 습관은 source_id와 수행 날짜의 unique 제약으로 회차 중복을 방지한다. 개인 완료 상태와 친구 확인은 독립적이다. 계획과 제출 인증 수정 UI는 제공하지 않아 확인 후 변경되지 않는다.

일기는 날짜당 본인 1개, 초안은 본인만 조회, 명시적 공개 후 방에서 조회한다. 본인 글/답글만 수정·삭제한다. 공개 후 수정은 공개 상태를 유지한다. 사진을 바꾸거나 삭제해 연결이 끊기면 상대의 새 다운로드는 차단된다. 이미 내려받은 파일은 회수할 수 없다.
