# 인계: '모두'·'할일'에서 지금 한칸 화면 그대로 쓰기 (다가오는·담아두기·타임라인·시간블럭)

- 브랜치: `codex/all-reuse-home` (기준 `origin/main` 1b7ad4a)

## 목표 (결 요청)
지금 한칸에 이미 있는 타임라인·시간블럭·다가오는·담아두기와 같은 기능을 하는 곳('모두', '할일' 오른쪽 칸)은 새로 만들지 않는다.
기존 화면을 그대로 써서 모양과 입력·클릭·끌기 규칙을 똑같이 맞춘다.

## 결이 정한 것 (2026-10-10 대화)
1. 오른쪽 '다가오는'은 '모두'의 눈 설정과 상관없이 지금 한칸과 똑같이 보인다.
2. '지난 할일 N개' 접힘은 없앤다(지금 한칸에 없음).

## 한 일
### 방식: 복사가 아니라 "빌려 쓰기"
- `index.html`에 `homeLoan`을 추가했다.
  - 지금 한칸의 DOM 덩어리(`#homeUpcomingPanel`, `#homeSomedayPanel`, `#homeTimelinePanel`, `#homeBlockPanel`)를 보이는 탭으로 옮겨 붙인다.
  - 지금 한칸으로 돌아가면 원래 자리로 되돌린다.
- 그리기 함수와 클릭·끌기·추가 처리기도 지금 한칸 것 하나만 쓴다. 그래서 한쪽을 고치면 양쪽에 같이 반영된다.
- 지금 한칸 목록 스타일이 `.home2-grid` 안에서만 걸리던 규칙은 빌려 간 자리(`.home-loan`)에서도 걸리게 넓혔다. 지금 한칸 화면 자체의 모양은 그대로다.

### 오른쪽 '다가오는 · 언젠가' ('모두'·'할일' 공용)
- 껍데기(`createOnekanSideAgenda`)만 남겼다. 하는 일은 목록 전환, PC 접기·펼치기 기억, 모바일 아래쪽 패널이다.
- 다가오는 = 지금 한칸 다가오는 그대로다.
  - 내일부터 7일, ‹ › 7일 이동, 날짜 라벨을 누르면 처음으로 돌아간다.
  - 제목 누르기 = 이름 수정, ⋯ = 메뉴.
  - 빈칸: 왼쪽 클릭 = 할일 입력, 오른쪽 클릭 = 종류 메뉴. 연속 입력이 된다.
  - 손잡이로 끌기(모바일은 길게 누르기). 체크·습관 체크도 지금 한칸과 같다.
- 언젠가 = 지금 한칸 담아두기 그대로다(정렬 선택, 그룹 칩, 더 보기, 위·아래 빈칸 추가, 끌기).
  - 예전 자체 목록에 있던 '날짜 없는 할일'은 지금 한칸 담아두기에 없어서 이제 나오지 않는다.
- 예전 자체 그리기 코드(14일 '더 보기', '지난 할일' 접힘, `.sa-row` 등)는 삭제했다.
- 빌려 간 목록에서 체크하면 가운데 보기도 바로 맞춘다(`renderLoanHosts`).

### '모두' 일 보기 = 지금 한칸 시간블럭·타임라인
- 보조 보기 '시간블럭/타임라인'에 따라 지금 한칸의 같은 화면을 보여 준다. 예전 엔진의 일 보기는 '모두'에서만 숨긴다.
- 날짜는 '모두' 위쪽 ‹ ›를 따르고, 지금 한칸의 날짜 이동 줄은 '모두'에서 숨긴다.
- 표시는 '모두'의 일 보기 종류 눈과 범주·그룹 눈을 따른다(`homeItemFilter`). 지금 한칸에서는 늘 꺼져 있다.
- 공유 창은 자기 필터가 따로 있어서 이 거르기를 빼고 모은다.
- 떠나면 지금 한칸에서 보던 날짜·보기를 되살린다. 지금 한칸 설정 `tok_home_view`는 바꾸지 않는다.
- 다른 탭에서 새로고침(`loadAll`)돼도 '모두'가 화면을 다시 빌려 가지 않는다.

### '모두' 주간 보드 (지금 한칸에 없는 보기라 모양은 유지, 규칙만 맞춤)
- 제목 누르기 = 이름 수정. 전체 수정은 ⋯ 메뉴(예전: 누르면 상세 창).
- 빈칸 = 지금 한칸 빈칸(`addSlotHtml`)과 같은 모양·규칙(`wireDateAddSlot`, 다가오는과 같은 함수).
- 다가오는·담아두기 행을 보드 열·월 달력 칸에 끌어 놓으면 그 날짜 종일이 된다(기존 `moveItemToZone` 규칙).

### 바꾸지 않은 것
- 월 달력의 항목 누르기는 그대로 상세 창이다.
  - 일정 탭과 같이 쓰는 엔진이라, 바꾸면 일정 탭도 같이 바뀐다.
  - 달력 칸이 좁아서 이름 수정 입력창을 띄우기 어렵다.
- '모두'는 운영자 전용 그대로다(`release-policy.js` 변경 없음). DB 변경 없음.

## 검증
- `tests/all-redesign.cjs` 16개 묶음 모두 통과(가짜 Supabase, PC 1440·1800, 모바일 390).
  - 새로 넣은 검증:
    - 오른쪽이 지금 한칸과 같은 DOM이다(복제 아님). 7일, 지난 할일 접힘 없음, 눈과 무관.
    - ‹ › 이동, 제목 클릭 이름 수정, 빈칸 추가.
    - 다가오는·담아두기 → 보드 열 끌기. 목록 기억. 지금 한칸으로 돌려준다.
    - 보드: 제목 클릭 이름 수정, 빈칸 연속 입력.
    - 일 보기: 같은 DOM, 종류·그룹 눈 반영, 날짜 연동, 제목 클릭 이름 수정. 떠나면 날짜·필터·자리 복원, 새로고침해도 다시 안 빌려 감.
    - 할일 탭도 같은 목록. 모바일 패널 안 목록.
- 회귀: 결과는 아래 '회귀 비교'에 적는다.
- 실행하지 못한 것: 실제 휴대폰 터치(길게 눌러 끌기), 실제 계정 데이터.
