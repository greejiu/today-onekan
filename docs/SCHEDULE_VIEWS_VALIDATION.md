# 일정 보기·공통 조작 구현 및 검증 (2026-10-03)

## 기준과 데이터 대응

최신 main `c9fcb07361fff46ebce34bfb40b2015ae52e97be`에서 `codex/schedule-views`를 시작했다. 원래 `codex/desktop-sidebar` 폴더의 미커밋·미추적 파일을 변경하지 않고 기존 관리 worktree를 재사용했다. 저장소/상위 경로에서 AGENTS.md를 발견하지 않았고 CODEX_HANDOFF 및 실제 화면·공통 기간·분류·반복 코드를 확인했다.

운영 `mmpsyajgyufdxmmnxqba`의 tok_events 컬럼을 읽기 전용으로 대조했다. 일정 원본은 기존 tok_events 한 행이며 `event_date/event_time/end_date/end_time/all_day/duration_minutes`를 OnekanPeriod로 읽는다. 기존 category_id는 일정 그룹, shared_category_id는 공용 범주다. 이름·메모·반복·분류는 보기나 기간 이동 때문에 변경하지 않는다. 기존 tok_time_blocks를 읽어 시간블럭을 표시한다.

새 DB 테이블·컬럼·RPC·권한 변경 및 운영 마이그레이션은 없다. 기간 저장은 기존 기간 검증 트리거와 사용자 소유 RLS를 사용한다. update는 항목 ID와 현재 사용자 ID로 제한하고 반환 행이 없으면 실패로 처리한다. 기존 `.update().eq().select().single()` 사용을 [Supabase update 문서](https://supabase.com/docs/reference/javascript/update)와 대조했다.

## 변경 파일과 보기

- index.html: 공통 전용 사이드바와 모바일 토글에 보드 추가, 달력 기간/표시 방식 및 목록·보드 조회/정렬 controls, 기존 상세·메뉴·추가·분류와 모듈 연결. 월간 날짜 칸·띠·더보기·선택 날짜 상세·월 선택기는 유지한다.

- assets/schedule-views.css: 기존 테마/accent 변수, 수평 스크롤 4일뷰·보드, 동일 높이 종일 영역과 시간축, 좁은 화면 controls. 기존 760px 경계와 하단바는 유지한다.
- tests/schedule-views.cjs: 실제 포인터 범위 선택·이동·종료 조절 및 보기/필터/오류/모바일 통합 검증.
- tests/home-layout.cjs, app-symbols.cjs, together-ui.cjs, deployed-navigation.cjs: 외부 요청이 차단된 fixture와 실제 배포 파일 확인에 새 로컬 자산을 연결한다.

최초 기본은 한달 달력이다. 1일/4일은 기준 날짜부터 연속 구간이며 이전/다음이 1일/4일 단위다. 한달은 월 단위로 이동한다. 날짜 입력과 오늘 버튼으로 드래그 없이 이동할 수 있다. 마지막 달력/목록/보드, 1일/4일/한달, 타임라인/시간블럭, 정렬·그룹화·보드 열 기준은 `tok_schedule_views:<user>`에 저장하며 계정 변경 시 재설정한다. 보기별 스크롤은 앱 사용 중 별도로 복원한다. 전체 메뉴 복원은 본문을 다시 그리지 않는다.

목록·보드는 동일한 명시적 조회 기간과 그룹 선택 필터를 사용하며 시작일이 기간 밖이어도 겹치면 포함한다. 이름/시작 날짜·시각 정렬과 없음/날짜/그룹/범주 그룹화를 제공한다. 보드는 그룹/범주와 미지정 열을 제공하며 분류 이동 드래그는 없다. 공용 범주와 보관된 연결도 누락하지 않는다. 기존 날짜 그룹의 오늘 이후 이동, 추가·상세·공통 메뉴 경로를 연결한다. 달력 눈 설정은 목록/보드에 적용하지 않는다.

시간블럭은 실제 저장된 구간과 겹치는 일정에 원본 ID를 반복 표시할 뿐 새 일정이나 완료 기록을 만들지 않는다. 부분적으로 밖에 걸치거나 블럭이 없는 시간 지정 일정도 별도 영역에서 접근할 수 있다. 블럭 추가는 실제 시작/종료 구간을 제안한다. 블럭 위에서 시간 이동/시각 드래그를 저장하지 않는다.

## 조작·호환

- 월간 빈 날짜 범위와 종일 영역은 포함되는 날짜 양 끝으로 추가창을 연다. 1일/4일 타임라인 범위는 명시적인 날짜·시각을 채우고 같은 날 최소 15분을 제안한다. 자동 저장하지 않는다.
- 날짜 이동은 시작/끝을 함께 이동한다. 타임라인 이동/종료 조절은 15분 스냅이며 실제 소요시간은 유지한다. 조회만 할 때 기존 09:07 같은 값이나 종료 값을 반올림하지 않는다. 다음 날 00:00 종료는 종료일의 항목으로 표시하지 않는다.
- 여러 날/자정 넘김은 원본 ID와 실제 기간을 유지해 각 날짜 겹치는 구간으로 표시한다. 타임라인 겹침은 별도 열이며 종일 영역 높이를 모든 날짜에 맞춘다.
- 미리보기, Escape/취소, 유효하지 않은 외부 드롭, 클릭 억제, 저장 중 중복 방지, 실패 시 원래 위치와 오류 표시를 제공한다. 미리보기 중 원본 배열은 수정하지 않으며 저장 성공 후에만 갱신한다.
- 종료 없는 기존 시간 지정 항목과 반복 일정의 직접 드래그 저장은 막고 기존 수정창으로 연다. 개별 회차/전체 반복 구분 모델을 새로 만들지 않는다. 레거시 날짜 이동은 OnekanPeriod.shift로 실제 저장 필드만 보존한다.
- 모바일 터치 드래그는 구현하지 않는다. 손가락 스크롤은 저장을 발생시키지 않으며 추가·상세·공통 메뉴·수정창에서 날짜/시간을 조작한다. 시간 추가, 종료 핸들의 클릭 수정, 목록/보드 상세, 날짜 입력으로 키보드 대체 경로를 제공한다.
