# 오늘한칸 공유 V1 (2026-09-29)

선택한 날짜의 타임라인·시간블럭을 공유용 PNG 한 장(내용에 따라 세로로 늘어남)으로 저장·공유한다.

## 사용 방법

- 진입 버튼은 두 군데 있다.
  - 지금 한칸: 타임라인/시간블럭 전환 탭 오른쪽의 **이미지로 공유**. 지금 보고 있는 날짜와 보기로 열린다.
  - 기록: 날짜별 기록 위의 **이미지로 공유**. 기록 화면에서 고른 날짜로 열린다.
- 미리보기 창에서 할 수 있는 것
  - 날짜를 ‹ › 버튼이나 날짜 칸으로 바꾸고, 타임라인/시간블럭 중에서 고른다.
  - 표시 옵션을 켜고 끈다(열 때마다 모두 켜짐).
    - 첫 줄 — 보여줄 종류: 일정 · 할일 · 습관.
    - 둘째 줄 — 할일·습관의 완료 상태와 빈 시간: 완료한 일 · 미완료한 일 · 빈 시간 숨기기.
    - 할일·습관을 둘 다 끄면 완료 상태 옵션은 적용할 대상이 없어 비활성이 된다. 켜 두었던 값은 기억한다.
- 버튼
  - **이미지 저장**: `오늘한칸_YYYY-MM-DD.png`로 내려받는다.
  - **공유하기**: 파일 공유를 지원하는 브라우저에서만 보인다. 운영체제 공유창을 열고, 취소해도 오류로 표시하지 않는다.

## 구현 방식

- 화면을 캡처하지 않는다. `index.html` 안의 `shareCompose`가 캔버스에 직접 그린다.
  - 논리 폭은 360px이고 3배로 그려서 1080px 너비가 된다.
  - 외부 라이브러리는 쓰지 않는다.
- 미리보기에 보이는 캔버스가 곧 저장·공유되는 PNG다. 그래서 내용·색·줄바꿈이 항상 같다.
- 높이 계산과 그리기가 같은 함수를 두 번 탄다(`draw=false`로 높이 계산 → `draw=true`로 그리기).
- 색은 현재 테마 변수(`--bg/--card/--line/--text/--sub/--accent…`)를 읽어서 쓴다.
  - 할일·습관 제목 그룹색은 앱 목록의 `.gc-title`과 같은 규칙의 색을 쓴다.
  - 타임라인 카드는 앱 타임라인처럼 그룹·범주색을 옅은 배경으로, 시간블럭 줄은 앱 시간블럭처럼 제목 글자를 그룹색으로 칠한다.
  - 일정은 범주색 동그라미로 표시하고 완료 체크박스를 만들지 않는다.
- 글꼴(설정에서 고른 글꼴·로고 글꼴)이 준비된 뒤 그린다. 로고 심볼은 문서 안의 `<symbol>`을 Path2D로 그려서 이미지 로딩이 필요 없다.
- 긴 제목은 띄어쓰기 단위로 줄바꿈하고, 한 단어가 폭보다 길면 글자 단위로 나눈다. 글자를 줄이거나 잘라내지 않는다.
- 출력 한계는 세로 15,500px(1080×15,500 ≈ 1,674만 화소 — 모바일 사파리 캔버스 한계 안)이다.
  - 넘으면 이미지를 만들지 않고 안내한다: ‘빈 시간 숨기기’를 켜거나 옵션을 줄이라고.
  - 긴 두 줄 제목 기준으로 항목 약 30~35개까지 들어간다.

## 표시 규칙

- 하루종일(시간 미지정)은 두 보기 모두 맨 위에 둔다. 임의 시간을 붙이지 않는다.
  - 타임라인 보기에서는 하루종일 카드도 시간 카드와 같은 들여쓰기(왼쪽 시간 라벨 칸 옆)에 맞춘다.
  - 타임라인 보기의 ‘하루종일’ 라벨은 시간 라벨(07:00 등)과 같은 글꼴 서식(왼쪽 칸, 작은 회색 굵은 글자)이다.
- 타임라인
  - 범위는 설정의 하루 범위다. 항목이 범위 밖이면 넓힌다(앱과 같은 규칙).
  - 1시간 줄마다 그 시간에 시작하는 카드를 쌓고, 줄 높이는 카드가 다 들어가게 늘어난다.
  - 겹치는 일정은 나란히 두지 않고 시간순으로 쌓는다.
- 카드에는 항목별 시간을 적지 않는다(2026-09-29 결 요청 — 제목+시간 두 줄이라 세로로 너무 길어져서).
  - 타임라인은 왼쪽 시간 라벨, 시간블럭은 블럭 이름·범위로 시간대를 알 수 있다.
  - 앞 시간에서 이어지는 항목은 줄 왼쪽에 그 색의 얇은 세로 막대로 표시한다.
- 빈 시간 숨기기
  - 켜면
    - 타임라인: 항목이 시작하지 않는 시간 줄은 아예 그리지 않는다. ‘비어 있음’ 표시도 없다(2026-09-29 결 요청). 앞 시간에서 이어지기만 하는 줄도 함께 숨긴다.
    - 시간블럭: 필터 적용 후 빈 블럭을 숨긴다.
  - 끄면 원래 시간 범위·블럭을 모두 보여 준다.
- 필터 후 표시할 항목이 0개면 ‘표시할 항목이 없어요’를 보여 주고 저장·공유를 막는다.
  - 완료·미완료를 모두 꺼도 일정이 남아 있으면 저장할 수 있다.
- 옵션은 이 창 안에서만 쓴다. 원본 데이터, 집 화면의 보기·필터는 바꾸지 않는다.
- 공유 과정에서 DB 쓰기는 없다(읽기만). 회차를 만들거나 완료 상태를 바꾸지 않는다.

## 날짜별 데이터 기준

| 날짜 | 할일·습관 | 일정 |
|---|---|---|
| 오늘·미래 | 집 화면과 같은 수집 함수(`todayAllDayItems`, `timedItemsForDate`)와 회차 판정. 현재 상태가 곧 그날 상태 | 그날 일정 |
| 지난 날짜 | 기록 탭과 같은 기준의 **저장된 완료 기록**만: 할일 `completed_date = 그날`, 습관 `tok_habit_logs.done_date = 그날` | 그날 일정 |

- 건너뛴 습관은 완료·미완료 어느 쪽에도 넣지 않고 V1 공유에서 제외한다.
- 지난 날짜에서는 **미완료한 일** 옵션을 막고 이유를 안내한다.
  - 미완료 할일은 ‘오늘로’·드래그로 날짜를 옮기거나 지우면 원래 날짜의 기록이 남지 않는다.
  - 그래서 그날 미완료였던 항목을 정확히 재현할 수 없고, 추정하지 않는다.
- 지난 날짜의 알려진 한계
  - 반복 일정은 날짜가 지나면 다음 회차로 옮겨지므로(`advancePastRepeatingEvents`) 지난 회차가 빠질 수 있다.
  - 수정·삭제된 일정은 현재 모습으로 보이거나 빠진다.
  - 완료 기록의 시간은 앱과 같은 규칙이다: 습관은 완료 때 남긴 시간 스냅샷 → 없으면 현재 습관 시간, 할일은 현재 `todo_time`.
  - `completed_date`가 비어 있는 예전 완료 할일은 날짜를 알 수 없어 넣지 않는다.
- 오늘 화면 규칙을 그대로 따르므로, 예전 날짜에 계획했다가 오늘 완료한 일반 할일은 오늘 공유 이미지에 나오지 않는다.
  - 집 화면 오늘 목록에도 나오지 않는 항목이다. 기록 탭 오늘 날짜에는 보인다.

## 후속 설계(이번 구현에서 보류)

### A. 정체성 → 프로젝트 안의 선택 메모 ‘되고 싶은 나’

- 별도 정체성 목록 대신 프로젝트 안에 선택적인 메모로 표시한다. 문구는 ‘되고 싶은 나’.
- 하위 프로젝트에서는 상위 프로젝트의 ‘되고 싶은 나’를 보여 준다.
- 기존 데이터를 보존하는 이전이 필요하다.
  - 대상: 기존 `tok_identities` 행과 `tok_projects.identity_id` 연결.
  - 예: 상위 프로젝트에 새 메모 칸을 추가하고, 연결된 정체성 이름을 복사한다. 원본 테이블은 한동안 남겨 되돌릴 수 있게 한다.
  - 한 정체성이 여러 프로젝트에 연결된 경우 각 프로젝트에 같은 문구를 복사할지는 구현 전에 정한다.

### B. 목록에 프로젝트명 표시

- 프로젝트마다 ‘목록에 프로젝트명 표시’ 옵션을 둔다.
  - 켜면 지금 한칸·할일·습관 목록에서 `프로젝트명 - 항목명`으로 보인다.
  - 끄면 항목명만 보이고 연결은 유지된다.
- 하위 프로젝트는 상위 설정을 따르되 개별로 바꿀 수 있다.
- 바로 연결된 프로젝트명만 쓴다(상위 경로를 붙이지 않음).
- 프로젝트 상세 안에서는 접두어를 생략한다.
- 실제 항목 제목은 수정하지 않고 화면에서만 조합한다.
- 사용 예: 드로잉 책 프로젝트는 표시, 도추미는 숨김.
- 신규 프로젝트의 기본값은 후속 구현 전에 정한다.
- 공유 V1은 이 옵션에 의존하지 않는다. 현재 제목 표시 로직(항목 제목 그대로)을 쓴다. 옵션이 생기면 공유 이미지도 같은 표시 함수를 쓰도록 맞춘다.
