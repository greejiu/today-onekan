# 한 화면 전체 맞춤 실험 (2026-09-28)

사용자 요청: 스크롤 없이 모두 표시해 보고, 별로면 되돌리기.

- 집 상단에 `한 화면에 모두 보기 / 기존 보기` 전환을 추가했다. 최초에는 전체 맞춤이며 선택은 localStorage에 저장된다.
- 전체 맞춤에서는 언젠가의 현재 필터 결과 전체, 그룹 칩, 남아 있는 할일을 펼친다. 가운데 선택 보기와 오른쪽 7일 범위는 유지한다.
- 카드 내부 높이 제한을 풀고 CSS zoom을 측정·조절해 사용 가능한 화면 높이에 넣는다. 목록 갱신, 보기 변경, 창 크기 변경 때 다시 계산한다.
- 이전 목록 개수·남은 할일 펼침 상태·보기별 스크롤 저장값은 보존한다. `기존 보기`로 이전 내부 스크롤 방식에 즉시 복귀할 수 있다.
- 축소된 타임라인의 드롭 시간 계산에는 축소 비율을 반영한다. 로고, DB, 공통 메뉴 모델은 변경하지 않았다.

검증: `node tests/home-fit.cjs`, `node tests/home-layout.cjs`, `git diff --check` 통과. Playwright/Chrome 및 네트워크 차단 메모리 모형 사용.

전체 맞춤 테스트: 1440×900, 1366×768, 390×844, 720×450에서 문서 가로/세로 넘침과 목록 내부 스크롤 없이 32개 언젠가 항목 표시. 보기 복귀·선택 유지·메뉴·체크·추가 검증. 기존 보기의 날짜/스크롤/드래그/모바일 회귀 검사도 통과.

제약: 모든 항목을 한 화면에 넣으므로 항목이 많으면 가독성과 클릭 영역이 크게 줄어든다. 많은 항목 테스트의 PC 축소 비율은 약 29~35%, 모바일은 그보다 작았다. 현재 비율과 기존 보기 복귀 안내를 항상 축소되지 않는 상단에 표시한다. 실제 모바일 기기 및 운영 계정 데이터 변경 테스트는 하지 않았다.

되돌리기: 사용자별로 `기존 보기` 선택. 실험 전체 제거는 이 실험 커밋을 revert하면 된다. 앞선 집 3열 구현은 유지된다.
