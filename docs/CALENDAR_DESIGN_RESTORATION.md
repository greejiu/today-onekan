- 타임라인·시간블럭: 착수 시 최신 main `06d0c62b75a4a23f26b5e5275d80836d0763094b`의 지금한칸 실제 화면, `renderAgendaTimeline`, `renderAgendaBlocks`, `renderAgendaAllDay`, `renderHomeTodayBlock`을 확인했다.
- `assets/agenda-markup.js`로 지금한칸의 시간축·카드·겹침 배치·블럭 HTML 생성부와 색상 계산을 추출했다. 지금한칸과 네 어댑터가 동일한 함수를 사용한다. 날짜·항목·범위·시각/제목/체크/메뉴 콜백을 전달하며 home 날짜/DOM/이벤트 핸들러를 공유하지 않는다.
- 지금한칸의 기존 행 CSS 선택자 범위를 네 페이지로 확장했다. 지금한칸의 간격·글꼴·색상·스타일 자체는 변경하지 않았다.

## 복원한 표시

월간 날짜 칸에는 목록 카드를 제거하고 작은 cal-chip만 표시한다. 원래 오늘 원, 선택 강조, 118px PC/72px 모바일 칸, 19px/15px 칩, PC 3줄/모바일 2줄, 주별 lane/spacer, cont-l/cont-r와 시작일·주 첫날 제목을 복원했다. 오른쪽/아래쪽 선택 날짜 상세는 원래 평평한 cal-day-row 구조이며 종류별 상태 조작은 상세와 기존 메뉴로 연결한다. 분류 색은 기존 어댑터 색을 유지한다.

원래 커밋에는 calExpanded 선언이 있지만 조회/펼침에 사용되지 않고 +N개 텍스트가 날짜 선택으로 연결되어 있었다. 이번 확정 요구에 따라 더보기 버튼의 실제 펼침/접기를 연결했고, 띠 줄이 어긋나지 않도록 해당 주의 행을 함께 펼친다. 모바일의 접힌 밀도는 원래 2줄이다. 월 제목·오늘·이전/다음과 원래 연월 선택 창을 네 페이지에 연결했다.

시간축은 설정된 하루 범위와 실제 항목의 범위를 합산한다. 00~24 고정이나 별도 sv-axis 렌더를 사용하지 않는다. 원래 ag-tl-grid/행 눈금/ag-tl-content/카드와 최소 높이·시각선·블럭 제목/점/평평한 행/add-slot을 사용한다. 여러 날의 축과 종일 높이는 공통으로 맞춘다. 각 날짜의 하루 구조를 읽을 수 있는 열로 나란히 두고 가로 스크롤한다.

1~7일, 기간과 자정 넘김·00:00 종료, 종류별 원본 ID/습관 회차·기록, 분류·프로젝트, 필터·눈, 반복·습관 이동 제한, 완료, 목록·보드, 모바일 탐색을 유지한다. 달력 칩이나 날짜 이동으로 완료 상태를 변경하지 않는다. DB/권한/마이그레이션 변경은 없다.

## 검증

기존 20개 격리 테스트와 새 design-restoration 검증을 실행한다. 기존 큰 카드/별도 축을 강제하던 DOM 선택자를 실제 복원 구조로 바꾸되 완료·반복·회차·드래그·실패·취소·식별자 검증은 유지했다. 월간 체크는 선택 날짜 상세, 여러 위치 완료 중복 방지는 실제 일간 회차 조각에서 확인한다.

동일 fixture/날짜/테마/크기로 원래 월간과 네 페이지의 칸/칩 크기·패딩·간격·글꼴·모서리를 비교한다. 지금한칸의 타임라인·시간블럭 DOM을 기준 커밋과 정규화 비교해 동일함을 확인한다. 시간축의 설정 06:00 시작과 날짜별 정렬, 작은 칩/주 띠/펼침·접기, 1일·7일·한달, 1440×900·1366×768·390px, 기본·검정·치즈 테마를 검증한다. 기존 공통 UI 테스트에서 1~7일, 760/761px, 계정/페이지 설정, 드래그 취소·쓰기 없는 조회도 확인한다.

모든 테스트 쓰기는 격리 fixture/PGlite에 한정한다. 실제 모바일 기기와 운영 사용자 항목을 수정하는 실계정 쓰기는 미검증이다. 기준·수정 화면은 Git에서 제외한 test-results/design-restoration에 보관한다.
