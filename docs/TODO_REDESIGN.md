# 할일 화면 단순화 — 2026-10-05

## 적용 범위

사용자의 마지막 요청에 따라 디자인은 할일 화면에만 적용한다. 습관·일정·지금한칸 화면의 디자인 확장은 사용자 평가 이후 진행한다. 공통 메뉴에서는 할일의 ‘날짜 변경’과 일정의 ‘날짜·시간 변경’을 제거하고 기존 ‘수정’으로 통합한다. 언젠가의 ‘날짜 정해서 할일로 옮기기’는 다른 기능이므로 유지한다.

GitHub main `f1c4d0de402200d0e5b1c3f67e493fcd2a34c684`에서 시작했다. 기존 베타 공개 제한과 운영자 권한 정책은 그대로 유지한다.

## 화면 변경

- 첫 줄: 월·주·일·목록·보드·언젠가 보기와 할일 추가.
- 둘째 줄: 선택 기간 이동, 오늘, 완료 상태, 보기 설정.
- 직접 기간 입력, 조회, 정렬, 목록 그룹화/보드 열 기준, 날짜 없는 할일 포함은 ‘보기 설정’에 접어 둔다. Escape로 접고 요약 버튼에 초점을 돌린다.
- 조회 기간은 상단 한 곳에 표시한다. 사용자 지정 기간은 같은 길이로 이전/다음 이동하고, 연도 경계를 표시하며, 연·월 선택 시 이전 사용자 지정 기간을 해제한다. 추가 창은 선택 기간 시작일을 사용한다.
- 할일 카드에서는 제목·체크·메뉴를 표시한다. 날짜·시간·범주·프로젝트·메모는 기존 데이터와 수정창에 유지하며 목록에서는 숨긴다. 월간 선택 날짜 목록도 제목 중심으로 표시한다.
- 전체 결과가 없으면 중앙 안내와 추가 버튼을 표시한다. 기존 할일이 있지만 조회 조건으로 제외된 경우에는 조회 조건 확인 버튼을 제공한다. 결과가 있는 보드의 빈 그룹 열은 유지한다.

## 변경 파일

- `index.html`: 접근 가능한 빈 상태와 설정 영역, 중복 날짜 메뉴 제거.
- `assets/todo-views.js`: 할일 전용 화면 구성, 기간 표시/이동, 빈 상태 및 설정 동작.
- `assets/item-views.js`: 할일 어댑터에만 적용되는 선택적 빈 상태 콜백. 다른 어댑터는 기존 동작 유지.
- `assets/schedule-views.css`: 할일 화면에 한정한 스타일. 기존 테마 변수 재사용.
- `tests/todo-redesign.cjs`: 화면·기간·필터·연결·반복·반응형 검증.
- `tests/shared-view-tabs.cjs`: 빈 할일 보드 대신 중앙 안내를 검증하도록 기대값 변경.

DB 스키마, 그룹/범주/프로젝트 연결, 반복/완료 저장 로직은 변경하지 않았다. 브라우저 테스트는 가짜 데이터로 외부 요청을 차단하여 진행한다.

## 검증

`todo-redesign`, `shared-view-tabs`, `todo-sidebar`, `todo-date-move`, `beta-release` 통과. 320·390·760·761·1366·1440px와 흰색·검정·치즈 테마에서 가로 넘침 없음. 빈 상태의 중앙 정렬, 접힌 설정의 접근성, 정렬/그룹화/기간 변경의 쓰기 없음, 반복 완료 후 다음 회차의 그룹·범주·프로젝트 연결 유지, 언젠가 입력 보존, 중복 ID와 실행 오류 없음 검증.

추가 실행한 예전 `calendar-ui.cjs`는 이미 숨겨진 `scheduleCalendarOptions`의 일간 버튼을 클릭하려다 시간 초과된다. 변경 전 origin/main의 HTML/JS/CSS를 그대로 사용한 대조 실행에서도 동일 실패를 확인했다. 현재 월·주·일 UI의 회귀 검증은 통과한 `shared-view-tabs.cjs`로 수행했다. JS 문법 검사 및 `git diff --check` 통과.
