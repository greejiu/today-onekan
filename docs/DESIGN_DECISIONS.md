## 상태의 의미
- 확정: 결이 명시적으로 선택한 목표 동작
- 제안/미확정: 선택이 필요하거나 아직 고르지 않은 것
- 충돌/확인 필요: 다른 결정이나 현재 구현과 맞지 않는 것
- 대체됨: 이후 결정으로 바뀐 것

### 미확정
- 오른쪽 탭 이름: 공통은 "날짜별/언젠가", 일정 설명은 "다가오는 탭"으로 달리 적혀 있다.
- 언젠가의 역할: 보기만 하는지, 달력으로 끌어 날짜를 정하는 재료인지.
- 지금한칸 상단의 "지금한칸, 추적"이 무엇을 뜻하는지.
- 추적과 기록의 경계. 제안: 추적은 타이머와 측정 통계, 기록은 완료한 일·습관 수행 같은 지난 내역.
- 모바일 배치(아이콘 사이드바, 오른쪽 사이드바).

### 충돌/확인 필요
- 2026-10-10 일정 통합(`docs/handoff/2026-10-10-calendar-merge.md`)에서 "할일·습관 그룹 눈은 사이드바에서 뺐고 거르기에도 쓰지 않음"으로 구현했다. FILT-01은 그룹으로도 거르는 것을 확정했으므로 현재 구현과 다르다.
