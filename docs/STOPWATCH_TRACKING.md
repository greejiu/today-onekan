# 스톱워치 구현 기록

기준 main: 18f8782. 기존 목표·달력·기록·비공개 방과 원본 데이터는 유지한다.

- tok_focus_sessions: 기존 2개 기록은 수정·변환·합산하지 않는다. 구간·시간대·스냅샷을 입증할 수 없는 과거 구조다.
- tok_stopwatch_sessions: 원본 todo UUID(삭제에도 유지), 사용자, 상태(running/paused/finished), 버전, 시작 당시 제목·그룹·공용 범주·프로젝트 ID/이름, IANA 시간대. finished 행 자체가 완료 기록이다.
- tok_stopwatch_intervals: 실제 실행 시작·끝. 일시정지는 구간을 닫고 계속은 새 구간을 만든다.
- tok_stopwatch_requests: 사용자별 요청 UUID와 요청 내용·응답. 트랜잭션 안에서 중복 요청을 재현한다.
- 원본/분류 FK는 의도적으로 두지 않는다. 시작 시 서버에서 소유를 확인하고 스냅샷을 저장한다. 삭제로 기록이 지워지지 않는다.
- 읽기는 소유 RLS. 쓰기는 공개 invoker RPC → 비공개 스키마의 제한된 definer 함수. 인증 UID를 반드시 검사하고 사용자 단위 트랜잭션 잠금·버전·활성 유일 인덱스를 함께 사용한다. 직접 항목 쓰기 권한을 추가하지 않는다.
- 시작/계속은 서버 시각. 정지/종료는 서버 시각에 보정한 요청 당시 시각을 보관하며 서버는 열린 구간 시작 이후·현재 시각 이하(2초 오차 허용)만 받는다. 실패 재시도에도 같은 요청과 시각을 사용한다.
- 통계는 finished 구간만 저장된 시간대의 날짜 경계로 분배한다. 범위는 최대 366일. ID별 묶음 표시 이름은 조회 대상 중 가장 최근 시작 스냅샷을 사용한다.

DB 먼저 → 앱 배포. 마이그레이션은 추가만 하며 이전 앱은 새 테이블을 사용하지 않는다. 앱에서 미적용 오류는 준비 안내와 재확인으로 표시한다. 관련 없는 마이그레이션은 적용하지 않는다.

## 검증 및 운영 적용

운영 적용: `20261004080014_tok_stopwatch.sql` / 프로젝트 `mmpsyajgyufdxmmnxqba`. CLI가 생성한 파일의 버전을 실제 운영 마이그레이션 이력에 맞췄다. 관련 없는 대기 마이그레이션은 적용하지 않았다.

적용 전 암호화 복구본의 현재 Windows 계정 복호화·해시 검증을 확인했다(원문 파일 생성 없음). 추가 구조의 롤백은 이전 앱으로 복귀하고 새 구조를 유지하는 방식이다. 기존 항목을 수정하거나 테이블을 삭제하는 복구는 필요하지 않다.

적용 전후 할일 123개·기존 focus 2개와 기존 RLS 정책 해시가 동일하다. 새 세션은 0개이며 운영 사용자 쓰기 테스트는 수행하지 않았다. 인증 역할의 읽기 RPC는 운영에서 실행됐고 보안 검사에 새 경고는 없다. 기존 Google Calendar 정책 안내·유출 비밀번호 보호 경고는 이번 변경과 별개로 유지된다.

- tracking-sql: 실제 로컬 PostgreSQL(PGlite)에 마이그레이션·소유 RLS·직접 쓰기 차단·활성 유일성·CAS·요청 멱등성·스냅샷·원본 삭제·할일 불변·일시정지·자정 및 DST 분배 검증.
- tracking-integrated: 같은 SQL에 두 독립 브라우저를 연결한 동시 시작·정지·종료, 실행 상태 새로고침, 종료 응답 유실 후 재접속·동일 요청 재시도 검증. PGlite는 트랜잭션을 직렬 실행한다. 운영 PostgreSQL의 병렬 연결 부하 테스트와 실제 두 기기는 미검증이다.
- tracking-ui: 검색·날짜 없는 할일·언젠가 제외·독립 메뉴·단순 오늘 내역·통계 5종·대상 변경·원본 불변·계정별 요청·실패·모바일 390/760/761·1440/1366·세 테마·콘솔/ID 검증.
- 기존 20개 테스트, 목표 UI/SQL, 승인된 달력·지금한칸 원형 비교 검증 통과.

실제 기기 절전·장기간 브라우저 종료·운영 쓰기와 운영 계정으로 로그인한 브라우저 조작은 미검증이다. 시간 계산은 화면 틱이 아닌 서버 시작/종료 시각으로 이루어진다. 표시에는 1초 단위, 저장·통계에는 밀리초 단위를 사용해 날짜별 합계와 전체 합계의 정밀도를 유지한다.

시간 재기의 오늘 내역은 해당 세션의 저장일(세션 시간대)이 오늘인 기록의 **전체 실행 시간**이다. 통계의 오늘은 해당 날짜에 실제 실행한 구간의 시간이다. 자정을 넘는 세션에서는 두 값의 목적이 다르다.
